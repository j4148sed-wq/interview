利用規約

制定日: 2026年11月17日 / 最終改定日: 2026年11月18日(バージョン 2026-11-18.2)

この利用規約(以下「本規約」)は、「セルフ面接練習」(以下「本サービス」)の利用条件を定めるものです。本サービスを利用するには、本規約に同意していただく必要があります。

第1条(運営者)

本サービスの運営者は 【運営者名 / ハンドルネーム】 です。お問い合わせ先は 【連絡先メールアドレス】 です。

第2条(サービス内容)

本サービスは、録音した質問音声を再生し、回答にかかった時間を記録することで、面接の練習を支援するWebアプリです。個人による運営で、無料で提供しています。

第3条(アカウント)

  1. 本サービスの利用には、メールアドレスによるユーザー登録が必要です。
  2. 登録情報(メールアドレス、お名前(漢字・カタカナ)など)は、正確なものを入力してください。
  3. パスワードは利用者自身の責任で管理してください。第三者による不正利用について、運営者は責任を負いません。
  4. 未成年の方は、保護者の同意を得たうえで利用してください。

第4条(取得する情報と利用目的)

  1. 本サービスは、次の情報を取得します。
    • メールアドレス、パスワード(暗号化された形で保管されます)
    • 回答時間の記録(質問、回答にかかった時間、日時)
    • 利用者が登録した質問(音声ファイル、質問文など)
    • 本規約に同意した日時
    • お名前(姓・名の漢字と、セイ・メイのカタカナ)
    • 原稿(暗記する回答の文章。利用者が入力した場合のみ)
    • 招待コードの送り先として責任者が登録した情報(お名前、送る招待コード)と、その照合・通知の状況
    • ログイン日時、使用した招待コード
  2. これらの情報は、本サービスの提供、ログイン認証、招待コードの案内(お名前の照合)、不具合の調査・改善のためにのみ利用します。
  3. 運営者が任命した「責任者」は、本サービスの運営のため、各アカウントの利用状況(メールアドレス、お名前、登録日、最終ログイン日時、規約への同意状況、回答回数・平均回答時間・最後に練習した日、追加した質問の件数、使用した招待コード)を閲覧できます。パスワードは暗号化されており、責任者を含め、誰も見ることはできません。回答の内容や、利用者が録音した音声を、責任者が閲覧することはありません。利用者が入力した原稿を、責任者が画面から閲覧することはありません。ただし、運営者は、データベースの管理上、技術的には保存された原稿を閲覧できる立場にあります。運営・不具合調査の目的以外で、閲覧することはありません。責任者は、招待コードの送り先(お名前と送る招待コード)を登録・削除でき、その案内の状況(通知中・確認済み・使用済み)を閲覧できます。
  4. データの保管・認証には、外部サービス(Supabase)を利用しています。取得した情報は同サービスのサーバーに保管されます。
  5. 「回答を録音する」機能をオンにした場合、練習中の回答は、お使いの端末のメモリの中だけで録音・保持されます。サーバーには送信・保存されず、運営者や責任者が聞くこともありません。聞き返したあと、確認画面で「削除して閉じる」を選ぶと削除されます。ブラウザを閉じた場合も失われます。
  6. 「原稿との照合」機能では、回答の録音を文字に起こす処理を、お使いの端末の中で、AIのモデルを動かして行います。音声や文字起こしの結果は、サーバーには送信されません。ただし、この機能を初めて使う際に、AIのライブラリ・モデル・読みの辞書が、外部の配信元(jsDelivr、Hugging Face)からお使いの端末へダウンロードされます。その際、通信元のIPアドレスなどが、配信元に伝わります。
  7. 法令に基づく場合を除き、本人の同意なく第三者に提供することはありません。

第5条(利用者が登録するコンテンツ)

  1. 利用者が登録した質問音声などの権利は、利用者に帰属します。
  2. 登録したコンテンツは、現時点では他のユーザーには公開されず、登録した本人だけが利用できます。
  3. 第三者の著作権などの権利を侵害するコンテンツは登録しないでください。

第6条(招待コードと限定コンテンツ)

  1. 招待コードを入力すると、運営者が提供する限定の質問セットを、ご自身のアカウントに追加できます。
  2. 同じ招待コードは、1つのアカウントで1回だけ使用できます。コードには、利用できる人数や期間の制限が設けられている場合があります。
  3. 限定コンテンツ(音声・質問文など)は、利用者本人が本サービス内で練習の目的に使うために提供するものです。第三者への再配布、公開、転載はできません。
  4. 招待コードを不特定多数に公開したり、不正な方法で入手・使用したりしないでください。
  5. 責任者が登録したお名前(漢字とカタカナ)が、新規登録時に入力されたお名前と一致した場合、その方がログインした際に、本サービス内で招待コードが通知されます。お名前の一致は本人確認ではありません。お名前を他人に知られている場合などには、別の方に通知される可能性があることを、あらかじめご了承ください。
  6. お名前が未登録のアカウントには、お名前の照合による通知は行われません。
  7. 招待コードを使用済みのアカウントには、同じ質問セットに運営者が追加した質問が、ログイン時に「自分の質問」へ自動で追加されます。運営者がセットから削除した質問は、すでに追加された質問も含めて、「自分の質問」から削除されます。

第7条(禁止事項)

  • 法令または公序良俗に反する行為
  • 他の利用者や第三者の権利・利益を侵害する行為
  • 本サービスの運営を妨げる行為(過度な負荷をかける、不正アクセスなど)
  • 他人になりすまして登録・利用する行為
  • 違法・有害なコンテンツをアップロードする行為

第8条(免責)

  1. 本サービスは現状有姿で提供され、特定の目的への適合性や、エラー・中断が生じないことを保証しません。
  2. システム障害、メンテナンス、外部サービスの停止などにより、データの消失や、サービスの中断・遅延が生じる場合があります。重要なデータは、利用者自身でも保管してください。
  3. 本サービスの利用によって生じた損害について、運営者は、故意または重大な過失がある場合を除き、責任を負いません。
  4. 本サービスの利用が面接などの結果を保証するものではありません。

第9条(サービスの変更・終了)

運営者は、事前の通知なく、本サービスの内容を変更し、または提供を終了することがあります。

第10条(退会とデータの削除)

退会(アカウントとデータの削除)を希望する場合は、第1条の連絡先までご連絡ください。ご本人の確認のうえ、アカウントと関連するデータを削除します。

第11条(利用の停止)

利用者が本規約に違反した場合、運営者は、事前の通知なく、その利用者のアカウントの停止や削除を行うことがあります。

第12条(規約の変更)

運営者は、必要に応じて本規約を変更できます。変更後の規約は本ページに掲載した時点で効力を生じ、重要な変更の際は、再度の同意をお願いすることがあります。

第13条(準拠法)

本規約は日本法に準拠します。
